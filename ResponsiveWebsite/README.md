# 🎨 DesignHub - Fully Responsive Website

A modern, fully responsive website for a professional design tool platform. Built with HTML5, CSS3, and Vanilla JavaScript.

## ✨ Features

### 🎯 Responsive Design
- **Mobile-First Approach** - Optimized for all screen sizes
- **Breakpoints:**
  - Extra Small: 320px - 480px
  - Mobile: 480px - 768px
  - Tablet: 768px - 1024px
  - Desktop: 1024px+
- **Flexible Layouts** - CSS Grid and Flexbox for responsive grids
- **Responsive Images** - Optimized for all devices
- **Smooth Transitions** - Seamless experience across devices

### 🧭 Navigation
- **Sticky Navigation Bar** - Always accessible
- **Mobile Hamburger Menu** - Collapsible on smaller screens
- **Smooth Scrolling** - Click navigation links for smooth scroll
- **Active Link Indicators** - Shows current section

## 🚀 Getting Started

### 1. Open the Website
Simply open `index.html` in any modern web browser.

```bash
# Using Windows
start index.html

# Using Mac
open index.html

# Using Linux
xdg-open index.html
```

### 2. Live Server (Recommended)
Use VS Code Live Server extension:
1. Right-click `index.html`
2. Select "Open with Live Server"
3. Website opens automatically at `http://localhost:5500`

## 🎨 Customization

### Colors
Edit the gradient colors in CSS:
```css
background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
```

### Fonts
Change font family in `style.css`:
```css
body {
  font-family: 'Your-Font', sans-serif;
}
```

### Content
Edit text content directly in `index.html`
Update images by replacing image paths
Modify colors in `style.css`
